# Forsidebannere

Karusellen på forsiden bruker disse filene (lagt inn i databasen av `Data/Seed/DemoData.cs`):

| Fil | Lenker til |
|---|---|
| `banner-1.jpg` | ingen lenke |
| `banner-2.jpg` | kategori `hudpleie` |
| `banner-3.jpg` | kategori `aloe-vera` |

**Bytt ut bildene** ved å overskrive filene med samme navn. Ingen kodeendring eller ny database trengs,
bare last siden på nytt (Ctrl/Cmd+Shift+R om nettleseren cacher).

Anbefalt format: **21:9**, f.eks. 2520 × 1080 px, JPG, under ca. 400 KB. Andre proporsjoner beskjæres til 21:9.

Bannere kan også administreres som admin under `/homepagemanagement` (rekkefølge, lenker, nye bilder).
